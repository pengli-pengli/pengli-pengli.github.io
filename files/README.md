# Files

Put downloadable files here, in the folder that fits:

- `cv/`: your CV
- `postprints/`: accepted manuscripts shared as green open access
- `preprints/`: preprints
- `teaching/`: teaching materials

A file at `files/postprints/Li_2026.pdf` is online at
`https://pengli-pengli.github.io/files/postprints/Li_2026.pdf`.
In the data files, write it as `/files/postprints/Li_2026.pdf`.

Keep each file under 100 MB (GitHub’s limit).
